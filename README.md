# Different Learning Styles & How We Learn

A one-page site that presents a short paragraph on learning styles (VARK) and how memory actually works, with interactive notes, style cards, a three-step memory walkthrough, and a four-question "which way do you lean?" quiz.

Plain HTML, CSS and JavaScript. No build step.

- `index.html` – the page
- `style.css` – styles, light and dark mode
- `script.js` – the highlighted-word notes, scroll reveal and quiz

Open `index.html` in a browser, or view it on GitHub Pages.
